PROMPT MAESTRO – DESARROLLO DE UNA APLICACIÓN WEB PROFESIONAL PARA RESTAURANTES, CAFETERÍAS, BARES Y HELADERÍAS

Quiero que actúes como un Arquitecto de Software Senior, Desarrollador Full Stack especializado en Python, Diseñador UX/UI, Especialista en Bases de Datos, DevOps y Experto en Seguridad Informática, con amplia experiencia desarrollando aplicaciones web comerciales.

Tu objetivo es diseñar y desarrollar una aplicación web moderna, escalable, profesional y lista para producción, destinada a restaurantes, cafeterías, bares, heladerías y cualquier negocio gastronómico.

No quiero únicamente ejemplos de código. Quiero construir un producto comercial real, con una arquitectura sólida, preparada para crecer y utilizarse en múltiples negocios.

Antes de escribir cualquier línea de código, analiza completamente el proyecto, propone la mejor arquitectura posible y justifica cada decisión técnica.

Todo el proyecto debe desarrollarse por módulos, avanzando paso a paso, asegurando que cada módulo quede completamente funcional antes de comenzar el siguiente.

OBJETIVO GENERAL

Crear un sistema web que reemplace completamente el menú físico y permita administrar toda la interacción entre clientes y el negocio.

El sistema debe permitir:

Mostrar el menú digital.
Mostrar promociones.
Mostrar menú del día.
Mostrar platos recomendados.
Permitir pedidos desde mesa.
Permitir Take Away.
Permitir Delivery.
Permitir reservas.
Administrar pedidos.
Administrar reservas.
Gestionar el menú.
Gestionar promociones.
Gestionar múltiples sucursales.
Generar estadísticas.
Funcionar perfectamente desde celulares, tablets y computadoras.
EL PROYECTO DEBE SER MULTIEMPRESA (SAAS)

La aplicación no debe estar diseñada para un único restaurante.

Debe funcionar como un sistema SaaS donde cualquier restaurante pueda registrarse y utilizar la plataforma.

Cada negocio tendrá:

su propio menú
sus propias categorías
sus propias mesas
sus propias reservas
sus propios empleados
sus propios pedidos
sus propias promociones
sus propios clientes
sus propios horarios
sus propias configuraciones

Los datos de cada empresa deben estar completamente aislados.

Debe ser posible que cientos o miles de restaurantes utilicen el mismo sistema sin interferir entre ellos.
